## ⚙️ Getting Started

Follow these steps to run the portfolio locally.

### Prerequisites

- A modern web browser.
- Git installed on your system.
- A code editor such as Visual Studio Code (optional).

### 1. Clone the Repository

```bash
git clone https://github.com/dhananjaychaudhary99/Portfolio.git
```

### 2. Navigate to the Project Directory

```bash
cd Portfolio
```

### 3. Open the Website

Open `index.html` directly in your browser, or use the **Live Server** extension in Visual Studio Code for local development.

No package installation or backend server is required for the static portfolio.

## 🚀 Deployment with GitHub Pages

The portfolio is hosted using **GitHub Pages**. The repository includes a GitHub Actions workflow for automated deployment.

**Workflow location:**

```text
.github/workflows/deploy.yml
```

### Deployment Steps

1. Push your changes to the `main` branch.
2. GitHub Actions runs the configured deployment workflow.
3. Once deployment succeeds, the updated website becomes available through the GitHub Pages URL.

**Live URL:** https://dhananjaychaudhary99.github.io/Portfolio/

> Ensure GitHub Pages is configured to use GitHub Actions as its deployment source and that the workflow has the required repository permissions.
