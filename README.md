## ⚙️ Getting Started.

```bash

```

```bash

```

### Run the Website.

Open **index.html** in your preferred web browser.

---

## 🚀 Deployment.

The portfolio is automatically deployed using **GitHub Pages** and **GitHub Actions**.

### Deployment Workflow.

```

.github/workflows/deploy.yml

```

GitHub Actions automatically deploys the website whenever changes are pushed to the **main** branch.
